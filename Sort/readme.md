ЗАДАЧА ТЕСТОВОГО ЗАДАНИЯ:
Тестовое задание направлено на оценку уровня квалификации и возможности реализации
выделенных проектов и оценки сроков реализации задания.
ПОСТАНОВКА ТЕСТОВОГО ЗАДАНИЯ:
Реализовать REST сервер с возможностью:
1. Возможностью настройки подключения к БД MSSQL при первом запуске приложения с
последующим сохранением информации в конфигурационном файле.
2. Передачи информации о пользователях, хранимых в БД под управлением MSSQL (структура
БД и набор тестовых данных наполняется в соответствии с присылаемым скриптом users.sql)
Реализовать REST клиент с возможностью:
1. Подключения к серверу
2. Запроса информации о пользователях и группах
3. Отображения информации о группах:
a. Название группы (поле [GroupList].[DisplayName]);
b. Кол-во пользователей и групп непосредственно входящих в данную группу
4. Детального отображение информации о пользователе:
a. Имя (поле [UserList].[DisplayName])
b. Фотография (поле [UserList].[Photo], формат JPEG)
c. Телефон (поле [UserList].[Phone])
d. Адрес (поле [UserList].[Address])
e. Примечание (поле [UserList].[Note])
5. Отображения отключенных аккаунтов серым цветом (поле [UserList].[AccountEnabled])
6. Поиска групп и пользователей.
Особенности БД и тестирования:
1. При разработке особое внимание необходимо уделить проектированию пользовательского
интерфейса (простота, удобство, наглядность).
2. Если поле [GroupTree].[ParentID] содержит значение 0, то группа является корневой
3. Пользователь всегда принадлежит какой-либо группе.
СРОК РЕАЛИЗАЦИИ:
5 рабочих дний с момента получения тестового задания.
